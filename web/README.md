# web/

Phase 0 serves the static page in `index.html` via `./start.sh` on `127.0.0.1:3000`.

Phase 1 replaces this with a Next.js 15 (App Router) TypeScript app: a live
boost-to-RTP table and an accumulator calculator, no login and no AI key.
The page should lead with one number. The 1.25× row looks different from
the 1.00× row without a caption explaining why. No hero section, no
gradient buttons, no stock photographs. Tabular figures, dark by default,
mobile first.
